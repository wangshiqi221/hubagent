# 轮辋模型按需误差评估

在聊天框输入“请评估一下生成的模型”，程序调用 `rim_evaluate_revolution`。仅在本轮明确提出评估请求时执行，不自动追加到重建流程。

仅计算重建轮辋到参考STL的单向距离。在重建表面按面积均匀采样5000点，到参考三角形内部、边或顶点求最短距离；参考表面不采样。默认使用当前唯一带来源的重建对象，也可指定 document_name、object_name 和 reference_stl_path。

## 计算参数

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| tolerances_mm | [0.2, 1.0, 5.0] | 误差阈值数组，单位mm；默认同时统计三个阈值 |
| sample_count | 5000 | 重建表面的采样点数 |
| mesh_deflection_mm | 0.02 | CAD离散偏差参数，不是重建误差 |
| seed | 2026 | 采样随机种子 |

误差阈值数组需包含1～32个互不重复的有限正数，程序按升序记录。旧的单值 tolerance_mm 参数不再接受；评估改用 tolerances_mm。拟合工具的 tolerance_mm 不受影响。

## 返回数据

版本为 single_direction_multi_threshold_v2。metrics.direction 为 model_to_reference，metrics.model_to_reference 包含 MAE、RMS、P95、采样最大误差和位置、采样点数，以及 area_ratios 数组：

```json
{
  "area_ratios": [
    {"tolerance_mm": 0.2, "within_tolerance_area_percent": 0.0},
    {"tolerance_mm": 1.0, "within_tolerance_area_percent": 100.0},
    {"tolerance_mm": 5.0, "within_tolerance_area_percent": 100.0}
  ]
}
```

以上数字仅为所有采样距离均为0.3 mm时的示例，不是实际轮辋结果。各比例按距离≤阈值统计，分母为整个重建表面的全部采样点；是累计比例而非0～0.2、0.2～1、1～5 mm的分段比例。三个阈值复用同一组采样距离，不影响采样点，不剔除超差点，不重复执行距离查询。所有点始终参与MAE、RMS、P95和最大误差统计。

返回结果还包括参考及重建网格面积。工具不自动对齐，参考按毫米解释；默认原始STL可能包含轮辐等非轮辋结构，单向误差也不能单独证明模型完整或工程验收通过。准备几何时自动重算并检查有效单实体，距离计算在后台执行。

使用示例：“请评估当前轮辋模型，分别给出0.2、1、5毫米以内的面积比例。”
