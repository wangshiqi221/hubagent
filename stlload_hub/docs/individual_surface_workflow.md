# 四个独立拟合面生成窗口切削实体

修改范围：stlload_hub。坐标单位毫米，拟合误差默认 0.1 mm，界面不显示误差控件。

## 界面操作

1. 打开 STL，逐个选择面 1–4。点击添加、Shift 点击删除，半径控制局部选区，拖动旋转。
2. 点击“拟合当前曲面”，独立拟合、显示和保存。符合误差的平面优先保留为精确平面；其余采用 B 样条曲面。结果在模型原坐标显示，四个面互不覆盖状态。
3. 四个面都完成后，点击“曲面求交”。输入圆角半径，0 表示不倒圆角。
4. 白色线显示实际面面交线。成功后青色显示封闭的切削实体；失败提示交线、裁剪封口或体积验证等具体阶段，并保留原四个面。
5. 改变某个选区使该面的拟合及组合结果失效，另外三面保留。加载其他 STL 清空全部状态。

## 实体构造

- 延伸量根据四个选区的共同包围盒计算，不再受单个很小面片限制。各次尝试从原始面的副本开始，停止于首个满足封闭要求的区域。
- 检查每个面是否至少与两个面产生交线；之后将四张支撑面和两个局部轴向封口平面一起交给 BOPAlgo_MakerVolume，计算交线、裁剪面并构造封闭区域。
- 候选区域必须由全部四个原始支撑面和两个端盖参与。多个候选需能唯一判断；含糊时不随意导出。
- 先在有选区数据支持的深度附近封闭，再将端盖轮廓沿轮毂轴直线延伸到整个模型包围盒两侧。这样不必将自由曲面沿深度外推几百毫米。无数据区域的直线延伸是切削工具构造约定，并不是原 STL 的真实孔壁拟合。
- 只对侧面之间的交接边倒圆角，不对端盖边倒圆角。圆角失败时显式提示并保留经过验证的无圆角实体。
- 输出必须是单个正体积、有界、方向正确的有效 Solid，只有一个封闭壳，且不存在自由边或非流形边。还需确认最终两个端盖位于指定轴向深度。

## 导出

继续使用 STL 旁的 section_output。单面前缀 fitted_surface_编号；实体前缀 window_cutting_solid。STEP 中直接保存 Solid，JSON 记录来源、毫米单位、容差、延伸策略和长度、圆角是否实际应用、警告及采样数据。单面 0.1 mm 是选区采样偏差要求，不代表延伸部分或新圆角的真实 STL 偏差。

## 验证

- test_surface_fit：曲面拟合、平面识别、无效数据拒绝及原有延伸函数回归。
- test_surface_join：很小的第四选区也可成体；封闭/体积检查；圆角成功；过大圆角回退；STEP 导出回读；从实体毛坯做布尔减法；缺失面拒绝。
- verify_window_solid：读取实际 STL 与 section_output 中各面最近的 JSON 采样记录，重新拟合并生成实体，STEP 导出后回读检查，再从扩大的模型包围盒测试毛坯中做减法。它不会改动原 STL 和原导出文件。

命令：verify_window_solid.exe <STL路径> <原选区JSON目录> <验证输出目录>

包围盒测试毛坯的减法通过，不等于已验证用户未来所有毛坯或全部布尔组合。实际切削目标需要另行指定。
